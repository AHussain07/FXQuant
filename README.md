# FxQuant: Forex Trading and ML Bias Platform

A full-stack final year project that combines a paper-trading dashboard with a machine-learning service for forecasting daily forex bias. Users can journal trades, simulate trades against live Alpaca prices, view a high-impact news calendar, and read intraday bias predictions generated by an XGBoost model.

## Features

- **React dashboard** for placing simulated trades and tracking performance
- **Trade journal** with notes and edit history
- **Real-time price feed** via Alpaca and Finnhub
- **ML bias service** with XGBoost models for EURUSD, GBPUSD, USDJPY, AUDUSD, and USDCAD
- **News calendar** scraped weekly from Forex Factory
- **Email-based authentication** using Nodemailer

## Prerequisites

Make sure the following are installed and available on your `PATH`:

- [Node.js](https://nodejs.org/) v18+ (ships with `npm`)
- [Python](https://www.python.org/) 3.9+ (ships with `pip`)
- [MongoDB](https://www.mongodb.com/), either a local instance or a MongoDB Atlas connection string

You will also need API credentials for:

- **Alpaca** (paper trading account)
- **Finnhub** (free tier API key)
- **Gmail** (an app password for sending verification emails)

## Installation

### 1. Clone the repository

```bash
git clone https://campus.cs.le.ac.uk/gitlab/ug_project/25-26/ah799.git
cd ah799
```

### 2. Install Node dependencies

The backend `package.json` orchestrates both the frontend and ML service via npm scripts, so install dependencies from inside `app/server/`:

```bash
cd app/server
npm install
```

Then install the frontend dependencies:

```bash
cd ..
npm install
```

### 3. Install Python dependencies for the ML service

The ML service depends on the following Python packages. Install them with `pip`:

```bash
pip install fastapi uvicorn pydantic numpy pandas xgboost requests pytz
```

## Environment Variables

Create a `.env` file inside `app/server/` with the following keys:

```env
# MongoDB
MONGODB_URI=mongodb://localhost:27017/fxquant

# Express
PORT=5000

# Email (Nodemailer / Gmail)
EMAIL_USER=your.email@gmail.com
EMAIL_APP_PASSWORD=your_gmail_app_password

# Market data
FINNHUB_API_KEY=your_finnhub_api_key
```

## Running the Application

The backend exposes a single `dev` script that boots **all three services concurrently** (Express backend, React frontend, and the FastAPI ML service).

From inside `app/server/`:

```bash
npm run dev
```

Once everything is up, the services will be available at:

| Service     | URL                       |
|-------------|---------------------------|
| Frontend    | http://localhost:3000     |
| Backend API | http://localhost:5000/api |
| ML Service  | http://localhost:8000     |

### Running services individually

If you prefer to run each service in its own terminal, use the scripts defined in `app/server/package.json`:

```bash
# From app/server/
npm run server    # Express backend with nodemon (port 5000)
npm run client    # React frontend (port 3000)
npm run ml        # FastAPI ML service (port 8000)
```

## Running Tests

### Backend (Jest)

The backend test suite mocks all external collaborators (DB, WebSocket, SMTP), so it runs offline without needing MongoDB. From inside `app/server/`:

```bash
npx jest
```

### ML Service (pytest)

From inside `machine-learning-model/`:

```bash
pytest
```
